# 早期离线原型范围

历史版本：2026-10-27。本文只描述 `code/index.html` 与 `code/assets/` 中保留的离线原型；当前桌面程序的功能与平台状态以 [项目首页](../README.md) 为准。

## 目的

探索 Docker 主机 → Compose 项目 → 服务 / 容器的导航方式，以及左侧资源树、服务列表、日志与详情区的操作布局。交互参考 IntelliJ IDEA Services，原型不依赖或控制 IDEA。

所有连接、容器状态、日志和指标均为示例。示例地址使用文档保留网段，不读取密钥，不发出 SSH / Docker 请求，不执行系统命令。

## 演示流程

1. 添加 SSH / 本地 Socket / TCP + TLS 连接，填写认证与 API 参数，模拟测试连接。
2. 展开主机与 Compose 项目，选择容器并切换日志、Inspect、资源与模拟终端。
3. 搜索日志、过滤级别、暂停跟随、换行、复制与导出示例日志。
4. 预览启动、停止与重启目标，仅改变页面内存中的模拟状态。
5. 演示客户端与服务端 API 范围不兼容，以及自动协商到 API 1.43。
6. 调整分隔区、主题和窄窗口布局。

## 边界

- 页面常驻“交互原型 / 示例数据 / 未连接服务器”提示。
- 模拟测试成功不代表网络连接或真实 Docker 操作成功。
- 原型不代表当前 React / Tauri 桌面程序的界面与安全实现。
- 可直接在浏览器打开 `code/index.html`，不需要安装依赖，不依赖 CDN。
- 内部调研截图不随公开仓库分发；公开示例不使用真实主机和业务标识。
