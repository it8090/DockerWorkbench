# Docker Workbench 0.1.5

首次 GitHub 开源发行，采用 MIT 许可证。

## 本次更新

- 更新请求遵循系统代理，支持需要代理才能访问 GitHub 的桌面环境。

- 新增单实例运行：重复启动时退出新进程，恢复并聚焦已有窗口，不再创建第二个 Go 核心。
- 更新重启时释放实例锁，退出后仍可正常重新启动。

- 接入软件更新：启动时自动检查，支持手动检查、下载进度、签名校验、安装及重启。
- 可关闭“启动时检查更新”，偏好保存在本机；检查失败不影响 Docker 连接。
- 更新安装失败后可重新检查并重试；重启前回收 Go 核心、日志和终端会话。
- 补齐中英文 README、贡献与安全说明，清理公开资料中的内部环境信息。
- 增加四种平台构建、更新包签名、完整性验证和 GitHub Releases 发布流程。

## 下载选择

| 平台 | 安装包 |
| --- | --- |
| macOS 13+ / Apple Silicon | 文件名含 `darwin-aarch64.dmg` |
| macOS 13+ / Intel | 文件名含 `darwin-x86_64.dmg` |
| Windows / x64 | 文件名含 `windows-x86_64.exe` |
| Linux / x64 | `linux-x86_64.AppImage` 或 `linux-x86_64.deb` |

`.app.tar.gz`、`.sig` 和 `latest.json` 用于自动更新。下载后可用 `SHA256SUMS.txt` 校验文件完整性。Linux 自动更新适用于 AppImage；deb 用户通过新 deb 包升级。

## 发行边界

这是早期版本。CI 构建成功不等于各平台桌面功能已完成原生运行验收，Windows / Linux 和 Intel Mac 仍需真实环境验证。

macOS 使用 ad-hoc 签名，未完成 Apple Developer ID 签名及公证；Windows 未使用 Authenticode 证书。更新包签名用于确认软件更新来源，与操作系统签名不同。

0.1.3 及更早的本地版本没有软件更新入口，首次升级请手动安装本版本。之后的新版本将通过软件更新提供。Windows 安装更新时会退出应用；重启会关闭连接、日志与终端会话，请先结束当前操作。
